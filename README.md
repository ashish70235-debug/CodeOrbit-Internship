# CodeOrbit Internship – Java Projects

This repository contains the Java projects completed as part of my
CodeOrbit Internship.

## 🚀 Projects

### 1. Simple Calculator
A console-based calculator that performs:
- Addition
- Subtraction
- Multiplication
- Division
- Input validation
- Division-by-zero handling

### 2. Student Grade Management System
A console-based system to manage student names and marks.

Features:
- Add student details
- Store student marks using ArrayList
- Calculate average marks
- Find highest marks
- Find lowest marks
- Input validation
- Formatted summary report

### 3. Bank Account Simulation
A console-based bank account simulation.

Features:
- Create a bank account
- Deposit money
- Withdraw money
- Check balance
- Transaction history
- Input validation
- Insufficient balance handling

### 4. Library Management System
A console-based library management system.

Features:
- Add books
- Display available books
- Search books by ID
- Issue books
- Return books
- Prevent duplicate book IDs
- Input validation
- Track book availability

## 🛠️ Technologies Used

- Java
- Java Collections Framework
- ArrayList
- Exception Handling
- Object-Oriented Programming (OOP)
- IntelliJ IDEA
- Git
- GitHub
